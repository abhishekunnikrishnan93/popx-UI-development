# PopX UI Development

A modern React-based implementation of the PopX mobile onboarding flow, built as a frontend assignment showcasing responsive design, client-side routing, form validation, and user interface development.

## Live Demo

https://popx-ui-development.vercel.app/

---

## Overview

This project recreates the PopX mobile onboarding experience using React. The application follows a complete user journey from landing page to registration, login, and account settings screens.

The project emphasizes:

* Clean UI implementation
* Mobile-first design
* React component architecture
* React Router navigation
* Form validation
* Responsive layout techniques

---

## Features

### Welcome Screen

* Modern onboarding interface
* Call-to-action buttons
* Navigation to registration and login pages

### Registration Screen

* User registration form
* Required field validation
* Email validation
* Phone number validation
* Password length validation
* Agency selection using radio buttons

### Login Screen

* User login interface
* Mobile-focused UI design

### Account Settings Screen

* User profile section
* Account information display
* Profile layout implementation

## Installation

Clone the repository:

```bash
git clone https://github.com/abhishekunnikrishnan93/popx-UI-development.git
```

Navigate into the project:

```bash
cd popx-UI-development
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

---

## Form Validation

The registration form validates:

* Required fields
* Email format
* 10-digit phone number
* Password minimum length

Users cannot proceed until validation requirements are satisfied.
